# SuperAwesomeMagicalOrchestrator 0.1.1

- **The Android app's first signed release.** The family's apps now only listen to an
  orchestrator app signed with this key, so signing in through it needs no extra tap to confirm
  the server.
- The `sam-orchestrator` command takes a device whose id starts with a dash (about one in
  sixty-four do) without reading it as an option.
- Signing out of an app forgets what was agreed with the orchestrator for it.
